# Aether Radio 设计落地说明

## 已实现

- Android 四栏导航：地球、发现、排行榜、我的，以及全局迷你播放器。
- Daybreak 日间和 Midnight Sonic 夜间配色、字体与组件；跟随系统、日间、夜间三档设置。
- 简体中文和英语即时切换，设置保存在本机。
- 发现页的搜索、流派、国家、语言和精选电台；列表由 Worker API 提供。
- 全球/语言/流派排行榜、前三名展示和分页列表。排序依据现有 API 的 `votes`。
- 可交互卫星地图、真实点位聚合、电台详情及播放入口。
- 本地收藏和最近播放记录，无账户依赖。

## 设计与数据边界

参考 `files/stitch_global_web_radio_app` 的 Daybreak / Midnight Sonic 截图与 `DESIGN.md`，以及 `files/PRD.MD`。其中部分截图文件为空或不是图片，采用同目录 HTML 和有效截图补足视觉参考。地图为圆形裁切的交互卫星地图，尚非可旋转 3D 球体。

现有 Worker 没有实时听众、正在播放曲目、码率切换、VIP 订阅、录制回溯、云同步及电台元数据翻译接口。这些能力涉及独立数据源、账户或服务端处理，当前没有以静态数字或不可用按钮代替。排行榜显示的 `votes` 不是实时在线人数；精选卡从当前可查询的电台中选择，不宣称每日人工更新。

## 验证

- Flutter 静态检查和测试；Android Debug APK 构建。
- 模拟器检查地图、发现、排行榜、个人中心的深浅主题与中英文布局。
- 语言、主题及收藏的本地持久化测试。
- 本地 Worker 健康检查、国家目录与 `countriesId` 电台筛选。
