# worldTuner 设计落地说明

## 已实现

- Android 四栏导航：地球、发现、排行榜、我的，以及全局迷你播放器。
- Daybreak 日间和 Midnight Sonic 夜间配色、字体与组件；跟随系统、日间、夜间三档设置。
- 简体中文和英语即时切换，设置保存在本机。
- 发现页的搜索、流派、国家、语言和精选电台；列表由 Worker API 提供。
- 全球/语言/流派排行榜、前三名展示和分页列表。排序依据现有 API 的 `votes`。
- 可旋转的 3D 卫星地球、DEM 地形、逐个显示的真实电台点位、详情及播放入口。
- 本地收藏和最近播放记录，无账户依赖。

## 设计与数据边界

参考 `files/stitch_global_web_radio_app` 的 Daybreak / Midnight Sonic 截图与 `DESIGN.md`，以及 `files/PRD.MD`。其中部分截图文件为空或不是图片，采用同目录 HTML 和有效截图补足视觉参考。地球由 MapTiler SDK 在 WebView 内绘制，接入卫星影像和 DEM 地形；它并非 Flutter 原生 3D 引擎。高程起伏需要放大至近景才能明显看到。

现有 Worker 没有实时听众、正在播放曲目、码率切换、VIP 订阅、录制回溯、云同步及电台元数据翻译接口。这些能力涉及独立数据源、账户或服务端处理，当前没有以静态数字或不可用按钮代替。排行榜显示的 `votes` 不是实时在线人数；精选卡从当前可查询的电台中选择，不宣称每日人工更新。

## 搜索页

发现页搜索框进入独立搜索视图，按 `files/stitch_global_web_radio_app/7` 的布局展示最佳匹配和分页电台列表。结果、热门排序、国家、语言、流派、收藏与播放均接入现有 Worker API 和本地播放器。设计稿中的示例曲名、实时听众数及 FM/DAB 频率未由 API 提供，因此界面改为显示真实国家、语言、编码和票数；电台封面使用 API favicon。

## 欢迎／注册入口

首次启动按 `files/stitch_global_web_radio_app/注册页` 展示欢迎页，保留声波品牌、网格轨道、入口按钮和深浅主题，并提供中英文文案。顶部“去登录”、账号密码登录、第三方入口及访客入口目前都直接进入应用，不执行真实鉴权；进入状态保存在设备本地，后续启动直接进入首页。手机号／邮箱注册和创建新账户会明确提示暂未开放。设计稿中的实时人数和示例电台没有真实数据源，因此改为通用的电台探索介绍。

## 验证

- Flutter 静态检查和测试；Android Debug APK 构建。
- 模拟器检查地图、发现、排行榜、个人中心的深浅主题与中英文布局。
- 语言、主题及收藏的本地持久化测试。
- 本地 Worker 健康检查、国家目录与 `countriesId` 电台筛选。
