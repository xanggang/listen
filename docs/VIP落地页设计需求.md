# WorldTuner VIP 落地页设计需求

## 1. 一句话任务

为 WorldTuner 设计一张 Android 端纵向滚动的 VIP 宣传页。让用户在首屏理解：**免费探索世界的声音，VIP 帮你把喜欢的声音带进每天的生活。** 页面应传达安静、精致、可信赖的全球电台体验，而非夸张的音质或版权承诺。

## 2. 产品背景与目标

- WorldTuner 是以 3D 地球为入口的全球网络电台应用。现有 Android 版支持地图探索、电台搜索、发现、榜单、播放、本地收藏和最近播放；有日间与夜间主题。
- 目标用户：经常听不同国家电台的人、希望整理常听电台的人，以及有通勤、工作、睡前等固定收听习惯的人。
- 页面目标：让用户记住 VIP 的三个核心价值——**收藏随行、轻松整理、按时收听**；为将来的订阅转化准备视觉和信息结构。
- 当前没有账户、会员、支付或云同步能力。因此本稿用“即将推出”的状态，不出现可执行购买承诺。

## 3. 会员权益分层

| 类型 | 权益 | 页面表述 |
| --- | --- | --- |
| 免费基础 | 地图探索、搜索、榜单、完整电台播放、本地收藏和最近播放 | 始终可以免费探索与收听 |
| VIP 核心 1 | 收藏与最近播放跨设备同步 | 喜欢的电台，换设备也能接着听 |
| VIP 核心 2 | 自定义收藏分组和场景列表 | 把城市、流派和心情整理成自己的收听空间 |
| VIP 核心 3 | 电台闹钟、预约播放、多组收听计划 | 到了你设定的时间，让熟悉的声音自然开始 |
| 后续探索 | 根据收听习惯发现相似电台、主题路线 | 如需出现，只放在“未来探索”区，不列为首发权益 |

**权益状态说明：** 上表 VIP 功能是计划中的产品方向，尚未实现。设计稿可展示目标体验的示意界面，但必须标注“功能规划示意”或“即将推出”，不可画成已可操作的真实服务状态。

## 4. 页面结构与建议文案

### A. 顶部导航

- 左侧返回；中间或右侧小型 `WorldTuner VIP` 标识。
- 页面不沿用四栏底部导航；从“我的”页进入，返回后仍回到原位置。
- VIP 徽记可用小颗星或声波环，不要做成金色皇冠。

### B. 首屏 Hero

- 视觉主角：夜色地球上少量发光电台点位，几条声音轨迹连接到个人收藏卡片。画面要保留地理探索特色，不使用与产品无关的唱片或耳机图库。
- 眉题：`WORLDTUNER VIP · 即将推出`
- 主标题：`让世界的声音，跟着你的生活走。`
- 副标题：`收藏随行，按心情整理，让喜爱的电台在对的时间响起。`
- 首屏小标签：`跨设备同步`、`专属收听空间`、`定时收听`
- 主按钮：`了解会员权益`，点击滚动至权益区；次按钮：`继续免费探索`，返回应用。
- 不出现“立即开通”“免费试用”“限时优惠”等购买暗示。

### C. 三个核心权益故事

每个权益用“场景一句话 + 简短解释 + 一张产品示意卡”的形式，卡片可交错排版，但阅读顺序固定。

1. **收藏随行**：`从这台设备收藏，下次打开仍是熟悉的频率。` 示意卡展示同一收藏列表在手机与另一设备之间保持一致。不要暗示当前已支持 iOS 或 Web 登录。
2. **轻松整理**：`为通勤、工作和深夜，各留一个声音空间。` 示意卡展示“通勤 / 专注 / 深夜”三个自定义分组及电台封面。
3. **按时收听**：`早晨醒来，或夜晚放松，让电台准时陪伴。` 示意卡展示电台闹钟与预约播放时间。不要使用保证电台 24 小时稳定在线的文案。

### D. 免费与 VIP 的关系

用简洁的两列对比卡说明：**免费版始终能探索和播放全球电台**；VIP 增加同步、整理与计划能力。避免把免费功能画成锁住或灰掉，也不要把搜索、地图、普通收藏列为 VIP 专属。

### E. 会员计划占位区

- 为未来月付和年付方案留出组件位置，可展示两个无价格的方案卡：`月度会员`、`年度会员`，状态均为`价格待公布`。
- 此区在当前概念稿中以轻量占位呈现，不显示具体金额、折扣、原价、试用天数或终身买断。
- 正式上线前必须补充真实价格、计费周期、自动续费与取消规则、恢复购买入口，再改为可购买状态。

### F. 常见问题与底部收束

- `不订阅还能听吗？` 可以。地图探索、搜索、榜单和电台播放继续免费。
- `VIP 什么时候推出？` 尚未公布时间，请勿给出具体日期。
- `已收藏的电台会消失吗？` 不会因页面展示会员概念而改变现有本地收藏；未来同步方案需另行确定迁移规则。
- 底部收束文案：`世界很大，喜欢的声音值得好好收藏。`
- 底部按钮：`继续探索电台`；可附小字 `VIP 功能规划中`。

## 5. 视觉与交互要求

- **优先交付夜间版**，同时出一张日间版首屏，用于检查现有双主题体系的延续性。
- 使用项目现有 Midnight Sonic / Aether Daybreak 视觉语言：深夜蓝背景、青色表示播放与信号，暖金仅点缀 VIP。夜间参考色：背景 `#0E1321`、青色 `#00F2FE`、金色 `#FCD34D`；日间参考色：背景 `#F8FAFC`、蓝色 `#0284C7`、金色 `#D97706`。
- 标题优先 Plus Jakarta Sans，正文 Inter；中文使用相近字重与清晰易读的系统字体回退。
- 手机稿建议以 390 × 844 逻辑像素为基准，左右留白 16 px；考虑顶部状态栏和底部手势安全区。正文不小于 14 px，辅助说明不小于 12 px，可点击目标至少 44 × 44 px。
- 首屏在常见手机高度内应看到完整主标题、价值说明及一个主按钮。滚动中可使用轻微的地球视差和声波动效，但静态截图仍应完整传达内容；尊重系统减少动态效果设置。
- 卡片里的电台名称、城市、封面、时间可使用明确标注的示例数据。不要绘制虚构的实时听众数、当前曲名或音质指标。
- 会员页是应用内纵向滚动页面，不设计为独立品牌网站；返回行为、弹性布局与现有播放器的关系要在稿中交代。建议进入会员页时隐藏常驻迷你播放器，以免遮挡底部行动区，返回后恢复。

## 6. 明确不要宣传的内容

- 不写 `320K / FLAC / 无损`：第三方电台流的实际音质由源站决定，当前没有音质切换服务。
- 不写 `直播回溯 / 云录制 / 离线下载`：尚无录制基础设施与内容授权方案。
- 不写 `无广告电台`：应用无法移除源电台节目或流中的广告。
- 不写 `解锁所有国家 / 绕过地区限制`：地理可用性和版权限制不能凭会员保证。
- 不写 `实时翻译 / 歌词识别 / 实时在线人数`：当前没有对应可靠数据与服务。
- 不把系统投送、基础睡眠定时器或基本可访问性做成 VIP 门槛。

## 7. UI 交付物与验收

1. 一张完整的夜间纵向页面，以及一张日间首屏；另附首屏、权益卡、方案占位卡的可复用组件。
2. 标明页面滚动、`了解会员权益` 锚点、返回、方案占位不可购买的状态。
3. 提供空状态/长文案适配，保证简体中文与英语标题替换后不会溢出。
4. 附上颜色、字体、间距、圆角、图标与动效说明，优先复用现有应用设计系统。
5. 评审重点：用户 5 秒内能否理解 VIP 的三项价值；能否看出免费版仍可正常使用；是否误以为当前已经能购买或享受未实现能力。

## 8. 可直接交给 UI 生成工具的提示词

> 请为 Android 全球网络电台应用 WorldTuner 设计一张高保真、可纵向滚动的 VIP 概念宣传页。应用核心是旋转 3D 地球探索全球电台，现有视觉为 Midnight Sonic 深夜蓝、青色信号光和少量暖金 VIP 点缀。首屏以夜色地球、电台光点和个人收藏卡片构图，标题“让世界的声音，跟着你的生活走。”，副标题“收藏随行，按心情整理，让喜爱的电台在对的时间响起。”，标注“VIP 即将推出”。下方依次设计跨设备同步、自定义收藏分组、定时收听三个权益故事卡，一张免费与 VIP 的简洁对比卡，两张无价格的月度/年度方案占位卡，以及常见问题。首屏按钮为“了解会员权益”和“继续免费探索”；全页没有立即购买、虚构折扣或已上线提示。保留移动端状态栏和安全区，采用 Plus Jakarta Sans/Inter 字体层级，输出完整夜间页、日间首屏和关键组件。产品界面要克制、可信、易读，避免夸张霓虹和通用音乐 App 模板。
